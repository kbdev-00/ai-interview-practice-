# 🎤 AI Interview Platform

An AI-powered interview application that simulates real interview scenarios using modern web technologies.

## 🚀 Features

- AI-based interview questions
- Real-time interaction
- User-friendly UI
- Secure authentication
- Scalable backend

## 🛠 Tech Stack

- Frontend: React / Vite
- Backend: Node.js, Express
- AI: Gemini / OpenAI API
- Styling: CSS / Tailwind
- Database: (MongoDB / Firebase – agar hai)
